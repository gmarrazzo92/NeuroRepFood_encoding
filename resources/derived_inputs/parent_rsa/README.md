# Parent-RSA derived input

`model_rdm_vectors.csv` is the exact 16-column historical parent-RSA table used
as an input by the ResCLIP reliability/recovery diagnostic.

It is bundled with the release because the corresponding Dataverse v1.0 files
contain only a 9-column subset. The nine common columns are numerically
identical to this historical file; the additional seven columns needed by the
historical diagnostic are absent from the public copies.

This file is not needed for the main M0-M4 encoding analyses.
